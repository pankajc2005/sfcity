🚀 SafeCity MVP — Feature List
1️⃣ FIR Data Ingestion

What it does

Allows FIR data to be added into the system

Feature includes

Upload FIR data via CSV / Excel

Preloaded historical FIR dataset

Basic validation (missing location, date, crime type)

Why this matters

Without structured FIR data, no crime analysis is possible.

2️⃣ Interactive Crime Map

What it does

Displays all crime incidents on a city map

Feature includes

Map view with zoom & pan

FIRs shown as points or heatmap

Click on a point to view FIR details

Why this matters

Police can visually understand crime distribution instead of reading tables.

3️⃣ Crime Filtering & Search

What it does

Helps users focus on relevant crime data

Feature includes

Filter by:

Date range

Crime type

Area / police station

Filters update the map in real time

Why this matters

Crime patterns change with time and location.

4️⃣ Crime Hotspot Detection

What it does

Identifies high-crime areas automatically

Feature includes

City divided into zones or grids

FIR count per zone

Zones marked as:

Low

Medium

High crime

Why this matters

Enables targeted policing instead of random patrols.

5️⃣ Pattern & Trend Insights

What it does

Shows when and what crimes happen most

Feature includes

Peak crime hours

Day-wise crime distribution

Most common crime types

Why this matters

Helps police plan patrol timing, not just location.

6️⃣ Patrol Recommendation (Advisory)

What it does

Converts insights into actionable suggestions

Feature includes

Text-based patrol recommendations

Based on:

Hotspots

Time patterns

Example

“Increase night patrols in Zone C between 9–11 PM.”

Why this matters

Data becomes a decision, not just a chart.

7️⃣ Accident-Prone & Sensitive Area Monitoring

What it does

Tracks non-crime safety risks

Feature includes

Accident-tagged FIRs

Mark sensitive zones:

Schools

Hospitals

Markets

Time-based accident analysis

Why this matters

Public safety is more than just crime.

8️⃣ Reports & Export

What it does

Allows sharing and offline analysis

Feature includes

Export filtered data as CSV

Download summary reports as PDF

Why this matters

Police decisions often need documentation.

9️⃣ Role-Based Dashboard (Basic)

What it does

Same system, different focus

Feature includes

Analyst view → trends & data

Officer/Admin view → hotspots & patrol suggestions

Why this matters

One product, multiple stakeholders.
